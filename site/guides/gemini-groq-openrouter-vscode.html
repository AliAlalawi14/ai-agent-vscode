Use Gemini, Groq or OpenRouter as a coding agent in VS Code

Stoat works with any provider that speaks the OpenAI API: Google Gemini, Groq, OpenRouter, Mistral, xAI Grok, Together, Fireworks, Azure OpenAI, or your company's own gateway. The model list is read live from the provider, so new models show up without an update.

1. Install Stoat

  1. Install Stoat. In VS Code open Extensions (Ctrl+Shift+X), search Stoat and install Stoat – AI Coding Agent. (Cursor, Windsurf and VSCodium find it on Open VSX the same way.)
  2. Open your project folder and click the Stoat icon in the activity bar (or press Ctrl+Shift+L).

2. Add the provider

  1. In Connect a model (or Settings → Add provider later), pick your provider.
  2. Click Get a key to open the provider's key page, create a key and paste it:
    • Gemini: Google AI Studio
    • Groq: console.groq.com
    • OpenRouter: openrouter.ai (one key for hundreds of models)
  3. Click Load models, tick the ones you want, then Save & connect.

Pick models that support tool calling. Agent and Plan modes use tools to read, search and edit files; models without tool calling can only answer questions.

3. Any other OpenAI-compatible server

Choose Custom server and enter the base URL including the version path (Stoat calls <base>/chat/completions and <base>/models), for example https://my-gateway.example.com/v1, and how it takes its key: a bearer token, an api-key header (Azure style), or none.

4. Mix providers

Add as many providers as you like and switch model per message from the menu at the top of the panel, for example a fast model for questions and a stronger one for big changes.

When the agent finishes, a review bar lists every file it changed. Click a file to see the diff, then Keep or Undo it (or Keep all / Undo all). Commands such as npm test or dotnet build always wait for your approval first.

FAQ

Does Stoat support Google Gemini?

Yes, through Gemini's OpenAI-compatible endpoint. Paste a key from Google AI Studio and pick the models to offer.

Can I use OpenRouter models in VS Code?

Yes. Add OpenRouter with one key and choose any of its models that support tool calling.
