How to use DeepSeek as a coding agent in VS Code

DeepSeek's models are strong at code and cost very little per request, which makes them a good fit for an agent that reads and edits many files. With Stoat you use your own DeepSeek key directly from VS Code: no subscription, no middleman.

1. Install Stoat

  1. Install Stoat. In VS Code open Extensions (Ctrl+Shift+X), search Stoat and install Stoat – AI Coding Agent. (Cursor, Windsurf and VSCodium find it on Open VSX the same way.)
  2. Open your project folder and click the Stoat icon in the activity bar (or press Ctrl+Shift+L).

2. Get a DeepSeek API key

  1. Sign in at platform.deepseek.com and create an API key.
  2. Add a little credit to your account (the API is pay-as-you-go).

3. Connect it in Stoat

  1. The first time you open Stoat it shows Connect a model. Pick DeepSeek.
  2. Paste the key and click Save & connect. The status dot turns green.
  3. Choose a DeepSeek model in the model menu at the top of the panel.

Your key stays on your machine, in VS Code's secret storage, never in a settings file. Requests go straight from your computer to DeepSeek.

4. Give it a task

Add input validation to the signup form and show an error under each invalid field.

5. Review the changes

When the agent finishes, a review bar lists every file it changed. Click a file to see the diff, then Keep or Undo it (or Keep all / Undo all). Commands such as npm test or dotnet build always wait for your approval first.

Tips

  • Turn on Settings → Show Metrics to see tokens and the cost of every reply.
  • Use Plan mode for bigger features: it asks questions first and writes a plan you can edit before anything changes.
  • You can add more providers later and switch model per message.

FAQ

Is DeepSeek good for coding agents?

Yes. DeepSeek's chat model supports tool calling, which an agent needs to read files, search and edit, and it is inexpensive per request.

Does Stoat cost anything?

No. Stoat is free and open source. You pay DeepSeek directly for the tokens you use.
