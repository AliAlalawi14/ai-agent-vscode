Stoat is an open-source AI coding agent for VS Code. Use any model with your own key (Claude, GPT, Gemini, DeepSeek, or a local model) and Keep or Undo every change it makes.

Install for VS Code Cursor · Windsurf · VSCodium Source on GitHub

Free · MIT licensed · Windows, macOS, Linux · no account, no telemetry

Why a stoat?

A stoat weighs about 200 grams and hunts rabbits ten times its size. Stoat is a small, open project built to compete with the big, closed coding tools: no subscription, no lock-in, and nothing changes in your code without your say.

🔑 Your key, your model

Claude, GPT, Gemini, DeepSeek, Mistral, Grok, OpenRouter, Azure, or any OpenAI-compatible API. Pay the provider only for what you use.

💻 Fully local if you want

Run it with Ollama or LM Studio and your code never leaves your machine. No key, no cost.

✅ Review, don't babysit

The agent edits without stopping at every file. When it's done, Keep or Undo each change, each file, or everything.

🗺️ Plan before building

Plan mode asks clarifying questions, then writes an editable Markdown plan that Build follows step by step.

🛡️ Safe by default

Works only inside your open folder, commands wait for approval, secrets are redacted, every change can be undone.

📦 Nothing to set up

The engine ships inside the extension and starts by itself. No Python, no .NET, no Docker. Connect a model in the panel and go.

Every change is yours to keep

When a run finishes, Stoat lists every file it touched. Open a side-by-side diff, keep what's good, undo what isn't. Undo never overwrites lines you changed yourself.

FAQ

Is Stoat free?

Yes. Stoat is free and open source (MIT). You pay only your model provider for what you use, or nothing with a local model through Ollama or LM Studio.

Which AI models does Stoat support?

Anthropic Claude, OpenAI, Google Gemini, DeepSeek, Mistral, xAI Grok, Groq, OpenRouter, Together, Fireworks, Azure OpenAI, local models through Ollama or LM Studio, and any OpenAI-compatible API. Agent and Plan modes need models that support tool calling.

Is Stoat an alternative to Cursor?

Stoat brings an agent workflow to regular VS Code: it edits files without stopping, then you Keep or Undo each change. Unlike a subscription editor, you choose the model and use your own key. It also installs in Cursor, Windsurf and VSCodium from Open VSX.

Does my code leave my machine?

Only to the model provider you choose, directly from your machine. Stoat has no server and no telemetry. With a local model, nothing leaves your computer.

Can I use my Claude Pro or Max subscription?

No. Anthropic allows subscription logins only in Claude.ai and Claude Code. Other tools, including Stoat, need an API key from console.anthropic.com or Claude through AWS Bedrock, Google Vertex or Microsoft Foundry.
