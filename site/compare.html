Stoat vs Cursor, Claude Code and Devin Desktop

Stoat is small next to these tools, and some things (a custom-trained autocomplete model, cloud agents that run while you sleep) need money and infrastructure that a small open project doesn't have. What Stoat can offer is different: free and open, any model including local ones, predictable cost, and the safest way to let an agent touch your code. Here is how they compare, as honestly as we can.

Checked in September 2026. Prices and features change often; follow the sources at the bottom for the current details. Windsurf was renamed Devin Desktop by Cognition on June 2, 2026.

Lock-inAny provider with your own key: Claude, GPT, Gemini, DeepSeek, Mistral, Grok, OpenRouter, Azure, any OpenAI-compatible API. Switch model per message.
PrivacyNo account, no telemetry, no Stoat server. Run fully local with Ollama or LM Studio, including offline autocomplete on a normal laptop.

Where the big tools are ahead

  • Cursor's Tab predicts your next edit anywhere in the file with its own trained models; Stoat's autocomplete is classic ghost text.
  • Background and cloud agents that keep working on several tasks in parallel, or while your laptop is closed.
  • Their own models, tuned for their product, and a polished, funded team behind them.

Choose Stoat if…

  • you want to keep VS Code and use the model you choose, including local ones;
  • you want the agent to prove its changes build and pass tests before it says "done";
  • you want no subscription, no account and predictable cost;
  • your code must stay on your machine;
  • you want to read the source of the tool that edits your code.

Small agent. Takes on the big ones. Free and open source.
